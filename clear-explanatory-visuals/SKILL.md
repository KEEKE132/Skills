# Clear Explanatory Visuals

Make the main idea easy to grasp at a glance. Solve the message, hierarchy, and reading order before adding style. Preserve the user's requested facts, language, and output format.

## Workflow

1. Confirm the subject and source material before designing. Define the audience, where the visual will appear, and one sentence the audience should remember. Do not replace an unavailable or ambiguous subject with a similarly named one without saying so.
2. Choose a structure that shows the real relationship: a sequence uses a path or timeline; a cycle uses a loop; a hierarchy uses a tree; a comparison uses aligned columns; an architecture uses grouped zones and clear directional arrows. Do not default to a center hub or a box for every noun.
3. Edit and group content before layout. Give each slide or canvas one focal message and a few meaningful groups. Remove repeated claims, filler subtitles, decorative labels, unnecessary caveats, and visible source notes that do not help the audience understand the point. Put research citations in speaker notes or a compact references area when provenance is needed. Never shrink type to force content to fit; split or simplify instead.
4. Make the scan path explicit for the audience's language and context. For Korean and English, place the entry point near the upper left, then guide the eye left to right and top to bottom unless the composition has a clear reason to differ. Keep steps in order, point arrows toward the next step, and make the first and last elements obvious. Use proximity, alignment, scale, and contrast to show grouping.
5. Set one coherent art direction before making the full set: canvas, colors, type roles, stroke weight, shape language, illustration style, and spacing. Keep that system consistent across every slide. Do not automatically choose a warm cream or beige canvas, muted pastel rounded-card look, generic AI gradient, or stock AI illustration; use those only when the user or a supplied reference asks for them. Do not make every slide the same card grid.
6. Choose typefaces deliberately rather than accepting the first available default. Pair a distinctive display face with a highly legible text face when appropriate, and verify that both render the requested language, including Korean glyphs. Do not mistake approachability for hand-drawn styling. Excalidraw-like wobbly lines, marker strokes, irregular outlines, and faux handwriting are not defaults for presentation decks; use them only when the user explicitly asks for that look. For ordinary presentations, use clean, deliberate lines, consistent shape geometry, and restrained accents.
7. Choose the output method for the job: use editable diagram elements when exact labels, relationships, or later edits matter; use image generation for illustrative scenes or when the user prefers a finished raster image. Keep image prompts focused on message, hierarchy, flow, exact text, palette, and whitespace.
8. Inspect at intended display size and review the whole set together. Verify the scan path, arrow direction, legibility, spacing, source accuracy, and consistency of color, type, and illustration. Remove anything that looks clipped, overlaps, floats without purpose, or competes with the main point. Revise the layout before adding detail.

## Quick check

Can someone identify the subject, main point, and where to begin in a few seconds? Can they follow the main path without reading every label? Does the full set look like one deliberate design? If not, regroup, simplify, and revise the art direction before delivery.
