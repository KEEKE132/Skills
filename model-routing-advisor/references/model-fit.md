# 모델 비교 근거

모델별 특성이나 추론수준의 효과를 판단할 근거가 필요할 때 읽는다. 아래는 2026-11-02에 확인한 공식 안내의 요약이다. 고정 추천표나 선택 가능 모델 목록이 아니며, 실제 환경의 버전·지원 설정과 최신 자료를 우선한다.

## 작업별 후보

- **Luna**: 범위가 정해진 작업, 분류, 반복 자동화의 후보.
- **GPT-6.1 Terra**: 화면 기반 작업, 간결한 글쓰기, 범위가 좁은 코드 수정의 후보.
- **GPT-6.1 Sol**: 시간·비용도 고려해야 하는 복잡한 작업과 여러 요소를 조율하는 결과물의 후보.
- **Astra**: 모호한 문제, 깊은 분석, 높은 완성도의 결과물의 후보. 비가역 위험이 없는 작업에도 적합성을 비교할 수 있다.

이 분류는 모든 작업에서의 우열을 뜻하지 않는다. 사용자가 선택한 모델에 해당한다는 이유로 그 항목에 가중치를 주지 않는다. 같은 입력·품질 기준으로 후보를 비교하고, 모델 비교 시 추론수준을 가능한 한 맞춘다. 추론수준을 비교할 때는 모델을 고정한다. 지원 설정이 달라 조건을 맞추기 어렵다면 그 차이를 밝힌다.

공식 출처: [Model selection](https://developers.openai.com/api/docs/guides/model-selection)

## 추론수준의 해석

추론수준은 사고량에 영향을 준다. 높은 수준이 모든 작업에 유리하거나 모델 간 능력 차이를 항상 상쇄하는 것은 아니다. 지원 값과 기본값은 모델마다 다르므로 확인한다. 추가 지연·비용과 품질 이점을 함께 판단한다.

공식 출처: [Reasoning models](https://developers.openai.com/api/docs/guides/reasoning)

공식 안내는 평가를 시작할 근거다. 실제 비교 결과가 없다면 “이 모델이 실패한다”거나 “검증됐다”고 쓰지 말고 작업 특성에 따른 예상 적합성으로 설명한다. 새 모델·버전의 이름만으로 기존 특성이나 서열을 승계하지 않는다.
